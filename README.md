# InfraDefect — Infrastructure Defect Segmentation System

Pixel-level detection of concrete and structural defects using SegFormer-B2 fine-tuned on annotated inspection images. Full-stack system: model training pipeline, FastAPI inference server, and React frontend.

## Defect Classes

| Index | Class | Color | Description |
|---|---|---|---|
| 0 | efflorescence | #ffff64 yellow | White mineral salt deposits on concrete surface |
| 1 | corrosion | #ffa500 orange | Rust staining, oxidation on metal components |
| 2 | crack | #ff4646 red | Hairline and structural cracks |
| 3 | spalling | #5082ff blue | Concrete surface delamination and chipping |
| 4 | exposed_bars | #32c832 green | Exposed or corroded reinforcement rebar |

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model

```bash
cd model_training
python train.py --data_dir ../roboflow_data --out_dir ../checkpoints --batch_size 4 --warmup_epochs 5 --main_epochs 45
```

Saves checkpoints/best_model.pth when a new best validation mIoU is reached.

To resume a stopped run:

```bash
python train.py --data_dir ../roboflow_data --resume ../checkpoints/last.pth
```

### 3. Evaluate the model

```bash
cd model_training
python evaluate.py --data_dir ../roboflow_data --checkpoint ../checkpoints/best_model.pth --save_visuals
```

### 4. Start the API

```bash
uvicorn backend.app:app --host 0.0.0.0 --port 8000
```

Or via Makefile:

```bash
make api
```

API available at:
- Swagger UI: http://localhost:8000/api/docs
- Health check: http://localhost:8000/api/health
- Predict: POST http://localhost:8000/api/predict

### 5. Start the frontend

```bash
cd frontend
npm install
npm start
```

Opens at http://localhost:3000. Requires the API to be running at port 8000.

## Dataset Format

Place annotated images in roboflow_data/ as paired JPEG + VOC-XML files:

```
roboflow_data/
├── image_001.jpg
├── image_001.xml
├── image_002.jpg
├── image_002.xml
└── ...
```

XML label names must match one of the recognised class strings (case-insensitive):

| Class | Accepted label names |
|---|---|
| efflorescence | "0 Efflorescence", "efflorescence" |
| corrosion | "1 CorrosionStain", "corrosionstain", "corrosion", "rust" |
| crack | "2 Crack", "crack", "cracks" |
| spalling | "3 Spallation", "spallation", "spalling" |
| exposed_bars | "4 ExposedBars", "exposedbars", "exposed_bars", "exposed rebar", "rebar" |

## Troubleshooting

CUDA out of memory — reduce batch size:

```bash
python train.py --batch_size 2
```

mIoU = 0.0000 during training — label names in your XML files likely do not match the class map. Scan your dataset:

```bash
cd model_training
python -c "
import glob, xml.etree.ElementTree as ET
from collections import Counter
labels = Counter()
for xml in glob.glob('../roboflow_data/*.xml'):
    for obj in ET.parse(xml).getroot().findall('object'):
        name = obj.find('name')
        if name is not None:
            labels[name.text.strip()] += 1
[print(f'  {c:>6}  {l!r}') for l, c in labels.most_common()]
"
```

Port 8000 already in use:

```bash
uvicorn backend.app:app --port 8080
```

npm start fails — ensure Node.js 16+ is installed:

```bash
cd frontend
npm install
npm start
```
